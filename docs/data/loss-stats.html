기사 한 건은 아래 관문을 순서대로 지난다. 표의 “어디까지 갔나”는 그 관문에서 몇 건이 떨어졌는지다.

  1. 기사 거르기문제를 만들어보기도 전에 기사 단계에서 뺀 것. 사설이거나, 다른 카테고리가 이미 쓴 기사.
  2. 문제 만들기만들어보라고 시켰는데 모델이 “이 기사로는 못 만들겠다”고 한 것. 응답이 깨졌거나 API 가 실패한 경우도 포함.
  3. 규칙 검사만들어진 문제를 저장 전에 정해둔 규칙으로 검사해 반려한 것. 최근에 쓴 용어를 또 썼거나, 형식이 어긋난 경우.
  4. 다른 모델이 풀어보기완성된 문제를 다른 회사 모델에게 풀려본 것. 답이 안 맞거나 정답이 둘 이상이면 반려.
  5. 발행다 통과해서 실제로 나간 문제. 탈락이 아니다.
