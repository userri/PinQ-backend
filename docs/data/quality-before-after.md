## 5. 같은 기준으로 잴 수 없는 것

- **원 172건 분석의 정의가 남아 있지 않다.** 2026-07-07 세션에서 `quizzes.tsv`(gitignore, 파일 없음)로 수행했고, 스크립트는 커밋된 적 없다. 남은 것은 메모리 요약(39~58%·85.7%·5건·55%/68%·38.1%)뿐이다.
  - 재측정에서 55.2% 는 원 값과 일치, 42.4% 는 39~58% 안, **금리 85.7% 는 재현되지 않는다**(60.7%). 원 중복 기준은 렉시컬 규칙보다 느슨했다.
  - "68%"·"38.1%" 는 5/19 프롬프트 개정 후 부분집합 비율이고 분모 크기가 없다.
- **개선 후 중복률 0% 의 한계**: 측정 기준이 곧 저장 직전 필터다. 필터는 60일 이력만 보는데 71일 전쌍에서도 0이라 필터 범위 밖까지 0이긴 하나, 어휘가 다른 의미 중복은 이 기준으로 안 잡힌다. 검수 로그는 그쪽을 "되풀이·소재 겹침" 관찰로 따로 센다(9/16 누적 16).
- 정답 방향 오류·치명 결함은 수동 판정이고 판정자가 다르다. 치명 등급은 7/12 신설이라 개선 전 값이 없다.
- 프롬프트 예시 파생: 개선 후 판정 기록 없음.
- 시도·탈락·백필: 8/16 이전 기록 없음(8/12~8/16 은 동결된 로그 파서 근사 5일분).

## 6. 쓸 수 있는 문장 / 쓰면 안 되는 문장

**보수적**
> 운영 문항 172건을 전수 분석해 유사 중복과 정답 길이 편향, 방향 오류를 수치로 확인하고, 카테고리별 예시 분리·이력 기반 중복 검사·룰베이스 검증·교차 모델 검증을 배포한 뒤 66일간 발행분 328문항을 매일 전수 검수해 치명 결함률 3.7% 와 검증 폐기율 62% 를 기록으로 남겼습니다.

**적극적** — 동일 코드·동일 모집단 정의로 비교 가능한 유일한 지표
> 저장 직전 렉시컬 중복 검사를 도입한 결과, 같은 기준으로 재측정한 유사 중복 문항 비율이 개선 전 42.4%(172건 중 73건, 금리 카테고리 60.7%)에서 개선 후 71일 349건 기준 0건으로 줄었습니다.

"같은 기준으로 재측정한" 을 빼지 않는다. 원 분석의 39~58%·85.7% 를 이 문장에 섞지 않는다.

**쓰면 안 되는 것**
- "중복률 39~58%→0%", "금리 85.7%→0%" — 개선 전 수치의 기준이 다르다.
- "결함을 완전히 제거" — 66일간 치명 12건, 정답 방향 오류 3건 재발.
- "매일 5문항을 안정적으로 발행" — 71일 중 2일 미달, 최근 31일 중 10일은 백필로 채움. "71일 중 69일 목표 수량 발행" 까지.
- "길이 편향 해소/감소" — 55.2%→76.2% 로 증가. "1.3배 이상 위반 0건" 만 가능하고 문턱 아래 밀집을 같이 적는다.
- "8회 실험으로 효과 검증" — 실험 #1~#8 은 채택 근거이지 전후 효과 측정이 아니다.
- "예시 파생 38.1% 감소" — 개선 후 측정 없음.

## 7. 앞으로 같은 기준으로 재려면

1. 렉시컬 규칙을 공식 중복 지표로 삼고 검수 회차에 `scripts/quality-metrics.py` 를 같이 돌린다(백업 덤프가 매일 오므로 입력은 있다).
2. 예시 파생 여부는 판정 기준을 글로 적고 검수 항목에 넣는다.
3. 의미 중복은 검수 로그의 "되풀이" 관찰을 카운트 필드로 고정한다.
