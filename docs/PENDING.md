# 대기 중인 후속 작업 (단일 진실)

세션·레포를 넘나드는 다단계 작업의 "다음 공"을 기록한다.
**규칙**: "X 후 Y" 의존 작업이 생기는 순간 여기 한 줄 추가. 완료 시 체크하고 다음 검수 커밋에 함께 반영.
매일 아침 퀴즈 검수(/quiz-audit) 마지막 단계에서 이 파일을 훑는다.

## 대기 중

- [ ] **검수 출구 조건**: 추적 중인 패턴 2개(keyword 주제서술형 · 카테고리 소재 이탈)가 실험 편입으로 닫히면 → 검수 주 2~3회로 첫 점감 (7/23 합의)
- [ ] **keyword 용어 2개 병렬 룰베이스 실험**: 3회 확인(7/25 351 · 7/27 362 · 7/28 368)으로 트리거 도달 — 워크벤치(trial_quiz)에서 "keyword 콜론 2개 이상 리젝" 룰 실험 후 채택 여부 결정 (7/28 승격)
- [ ] **미풀이 북마크 익일 죽은 링크 → 방침 ⓓ 결정, 프론트 배포 대기**: 전일 미풀이 북마크의 "풀러가기"가 오늘 세트로만 이동해 그 문제를 풀 경로가 없던 문제(7/26 실증).
  **결정: ⓓ 단건 풀이 라우팅** — "풀러가기"를 해당 quizId 단건 풀이 화면으로 연결. 요청서 `docs/api/unsolved-bookmark-routing-request.md` 프론트에 전달함.
  근거: `POST /api/quizzes/{quizId}/answer` 가 quiz_date 를 검사하지 않아 **지난 문제도 이미 채점 가능**하고, attempt 는 제출 당일로 기록돼 **소급 이슈가 발생하지 않음**(ⓑ의 소급 우려는 오판). ⓐ(해설 전환)는 미풀이 마스킹을 깨는 치팅 경로라 기각, ⓒ(자동 제거)는 사용자 의도 폐기라 기각.
  **백엔드 작업 없음** — 필요한 API(`GET /api/me/attempts/{quizId}`, 채점) 모두 배포 완료. 프론트 라우팅 변경만 남음
